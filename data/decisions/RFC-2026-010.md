# RFC-2026-010: Event-driven loyalty service on Azure (Kafka + Azure Functions)

## Status
Accepted → DEC-2026-011

## Context
Legacy batch points engine misses same-day accrual; Black Friday peaks 20x.
## Options
(1) Batch on Databricks; (2) **Kafka (Event Hubs) + Azure Functions with idempotent consumers**; (3) Vendor SaaS loyalty.
## Recommendation
Option 2. Authors: Ananya Krishnan (architecture), **Deepa Narayan (consumer/idempotency design, DLQ replay)**, Mohit Saxena (review).
