# Client Data Handling Standard (v2)

**1 Classification.** Public / Internal / Confidential / Client-Restricted (client PII and production data).

**2 Devices.** Client-Restricted data may be accessed only from Northwind-managed, MDM-enrolled, disk-encrypted devices, over VPN, and only where the client contract permits.

**3 Storage.** No download of client-restricted data to local storage. Use only client-provided VDI/Citrix where the contract requires it.

**4 Access.** Access is granted per project via an access-request ticket approved by the PM, and reviewed **monthly** by the PM (ISO A.5.18).

**5 Violations.** A violation is a security incident under POL-SEC-IR.
